1  建模：从牛顿方程到 ω̇ = b₀u + d

1.1 机械结构

底盘
 └─ 达妙 DM4310        ← 大 yaw，转轴竖直
     └─ roll 电机（锁死不用）
         └─ 大疆 GM6020 ← 小 yaw，转轴竖直
             └─ 顶板 + C 板（含 IMU）

两个 yaw 轴都竖直且平行，所以角度可以直接相加：

θp = θb + θs   ⟹   ωp = ωb + ωs (1.1)

1.2 载荷的转动方程

对载荷（顶板）绕竖直轴列牛顿第二定律，作用在它上面的力矩有三项：

  • 小 yaw 电机的驱动力矩 τm = kt i（i 是电流，单位 A）
  • 轴承的粘滞摩擦 −Bs ωs
  • 轴承的库仑（干）摩擦 −τf · sgn(ωs)
Jp dωpdt = kt i − Bs ωs − τf sgn(ωs) (1.2)
摩擦项写的是 ωs 而不是 ωp —— 因为轴承夹在小 yaw 转子和它底座（大 yaw）之间，摩擦取决于相对运动。

1.3 电流 → counts

控制帧 0x1FE 里 ±16384 对应 ±3 A，所以

i = 316384 u   [A]

代回 (1.2)，两边除以 Jp：

dωpdt = ktJp · 316384 u  −  BsJp ωs  −  τfJp sgn(ωs) (1.3)
b0  ≡  ktJp · 316384   (1.4)

b₀ 是整套算法里唯一需要"知道电机多大多重"的数。

1.4 换到相对坐标系 —— ★ 解耦的关键一步

用 (1.1) 把 dωp/dt 换成 dωs/dt + dωb/dt：

dωsdt + dωbdt = b0u − BsJpωs − τfJp sgn(ωs)

移项：

dωsdt = b0u + [ −BsJpωs − τfJp sgn(ωs) − dωbdt ]    (1.5)

中括号里那一整块，就是 d。

1.5 这个式子的意义

  • 状态量是 ωs（相对角速度），不是绝对角速度。小 yaw 只对"自己相对大 yaw 转了多少"负责。
  • d 里面包含了 −dωb/dt —— 大 yaw 的角加速度给小 yaw 带来的拖拽力。它和我们不知道的摩擦力被放进了同一个筐里。
  • 但负载质心偏出轴以后，大 yaw 的拖拽项和离心项都是可测的已知项，应该显式拆成 acouple，见 1.7。
已知的 acouple 用前馈直接抵消，ESO 只估 dres —— 这才是加负载后的正确解耦方式，见 1.7。

1.6 为什么要把模型写成这个形状

(1.5) 的意思是：从 u 到 ωs 是一个一阶系统；而位置 θs 是 ωs 的积分，所以从 u 到 θs 是二阶系统。

自抗扰（ADRC）的核心思想：

把一切不确定的东西（摩擦、大 yaw 拖拽、b₀ 估错的部分、负载变化……）统统塞进 d，用一个观测器实时估它，然后在控制量里减掉。减掉之后，剩下的就是一个干净的双积分器：
dωs/dt = u0

一个双积分器怎么控制，是教科书问题 —— 这就是第 3 节。

1.7 负载质心偏出轴：把大 yaw 的力显式拆出来

加上负载后，质心不在小 yaw 轴上了。设：

  • m：负载质量
  • r：质心到小 yaw 轴的水平距离
  • d：大、小 yaw 轴间距
  • α：质心在小 yaw 坐标系里的固定方位角
  • J0：小 yaw 转子 + 顶板绕自身轴的惯量
  • Jc：负载绕自身质心的竖直轴惯量

小 yaw 侧的总惯量由平行轴定理得到：

Js = J0 + Jc + m r² (1.6)

质心位置（大 yaw 轴在原点）：

xC = d cosφb + r cos(φb+θs+α)
yC = d sinφb + r sin(φb+θs+α) (1.7)

求导得速度平方：

vC² = d²φ̇b² + r²(φ̇b+θ̇s)² + 2d r φ̇b(φ̇b+θ̇s) cos(θs+α) (1.8)

只保留与 θs 有关的动能：

T = ½Js(φ̇b+θ̇s)² + m d r φ̇b(φ̇b+θ̇s) cos(θs+α) + [与 θs 无关的项] (1.9)

对 θs 列拉格朗日方程：

∂T/∂θ̇s = Js(φ̇b+θ̇s) + m d r φ̇b cos(θs+α)
d/dt(∂T/∂θ̇s) = Js(φ̈b+θ̈s) + m d r[φ̈b cos(θs+α) − φ̇bθ̇s sin(θs+α)]
∂T/∂θs = −m d r φ̇b(φ̇b+θ̇s) sin(θs+α) (1.10)

相减，正弦项合并：

Js(φ̈b+θ̈s) + m d r[φ̈b cos(θs+α) + φ̇b² sin(θs+α)] = τs (1.11)

移项、除以 Js，并代入 τs = kt(3/16384)u − Bsθ̇s − τf sgn(θ̇s)：

θ̈s = b0u + acouple + dres (1.12)
b0 = kt(3/16384)/Js

acouple = −φ̈b(1 + k cos(θs+α)) − k φ̇b² sin(θs+α)

dres = −(Bs/Js)θ̇s − (τf/Js) sgn(θ̇s) + 未建模项

k = m d r/Js
关键变化：acouple 由可测量 φ̇b、φ̈b、θs 直接算出，不再交给 ESO。ESO 只估 dres。

重力项

V = m g zC,   zC = 常数  ⟹  ∂V/∂θs = 0

两轴都竖直，质心只在水平面内移动，高度不变；重力与转轴平行，绕轴力矩恒为 0。质心变化进入的是 m r² 和 k，不是重力项。

前馈和观测器怎么改

uff = −acouple/b0 = φ̈b/b0 + m d rkt·3/16384 [φ̈b cos(θs+α) + φ̇b² sin(θs+α)] (1.13)

ESO 的模型输入只用反馈部分 ufb，不包含 uff：

dz1/dt = z2 + b0ufb + β1(y−z1)
dz2/dt = β2(y−z1)  ⟹  z2 → dres (1.14)
如果 ESO 看到的是 ufb+uff，z2 会估到 acouple+dres，控制律再减一次 z2/b0，就变成双重补偿。所以代码里 out_last 只记反馈部分。

第 2、3 节的其他公式不变，只是把 u 理解成 ufb，把 d 理解成 dres。

数值量级

kt·3/16384 = 1.355×10−4 N·m/count
J0 = 1.355×10−4/0.14 ≈ 9.7×10−4 kg·m²
m r² ≈ 0.6×0.125² ≈ 9.4×10−3 kg·m²
Js ≈ 1.0×10−2 kg·m²，b0 ≈ 0.013
k = m d r/Js ≈ 0.66
工况acouple 量级换算电流
大 yaw 4 rad/s 匀速≈ 11 rad/s²≈ 850 counts
大 yaw 11 rad/s 匀速≈ 80 rad/s²≈ 6200 counts
大 yaw 10 rad/s² 加速≈ 17 rad/s²≈ 1300 counts
大 yaw 100 rad/s² 加速≈ 166 rad/s²≈ 12800 counts
方向与相位：α 随编码器零位变化，先填 0；如果前馈让误差变大，把 g6020.ctrl.ff_sign（或宏 GIMBAL_6020_FF_SIGN）改成 −1，再单独辨识 α。第一次测试请把大 yaw 转速压到 1–2 rad/s。前馈开关和几何参数在 Watch 里都能直接改：ff_enable、load_mass、load_r、axis_d、load_alpha。

2  ESO：把扰动估出来

2.1 把 d 当成一个新的状态

设 dd/dt ≈ 0（扰动变化比观测器慢就行）。构造增广状态 x1 = ωs，x2 = d：

dx1/dt = x2 + b0u
dx2/dt ≈ 0
y = x1   (可测：相对角速度) (2.1)

这就是"扩张状态观测器"名字的由来：把未知扰动"扩张"成一个状态。

2.2 龙伯格（Luenberger）观测器

对 (2.1) 套标准观测器结构，增益 β1, β2：

dz1/dt = z2 + b0u + β1(y − z1)
dz2/dt = β2(y − z1) (2.2)

直觉：

  • z1 用"模型预测 + 实测误差修正"来跟踪真实的 ωs
  • z2 是误差的积分。只要 z1 ≠ y（模型和实测对不上），就说明有没建模的力，z2 就朝那个方向长

2.3 定 β1, β2：双重极点配置

令误差 e1 = x1 − z1，e2 = x2 − z2。两式相减：

de1/dt = e2 − β1e1   ,   de2/dt = −β2e1
⟹   d²e1/dt² + β1 de1/dt + β2e1 = 0 (2.3)

观测误差是一个标准二阶系统！希望它又快又不振荡 → 取双重极点 −ωo：

s² + β1s + β2 = (s + ωo)² = s² + 2ωo s + ωo²
β1 = 2ωo  ,   β2 = ωo² (2.4)

误差响应：

e1(t) = e1(0)(1 + ωo t) e−ωo t (2.5)

只有一个参数 ωo 要选，它直接就是"多快估出扰动"。代码里 GIMBAL_6020_ESO_WO 就是它。

这就是"带宽参数化"：不用分别调两个增益，直接说"我要观测器多快"。

2.4 离散化（代码里就是这么写的）

前向欧拉，dt = 1 ms：

z1[k+1] = z1[k] + ( z2[k] + b0u[k] − 2ωo(z1[k] − y[k]) ) dt
z2[k+1] = z2[k] − ωo²( z1[k] − y[k] ) dt (2.6)

代码里的 err = z1 - yr 就是 −(y − z1)，所以写成：

float err = c->z1 - yr;
float b1  = 2.0f * c->wor;
float b2  = c->wor * c->wor;

c->z1 += (c->z2 + c->b0 * c->u_last - b1 * err) * dt;
c->z2 += (-b2 * err) * dt;

2.5 离散稳定性（顺便算一下）

误差矩阵：

Ac = [ −2ωo   1−ωo²   0 ]   ⟹   Ad = I + Ac dt = [ 1−2ωodt   dt−ωo²dt   1 ]
tr Ad = 2 − 2ωo dt  ,   det Ad = (1 − ωo dt)²

特征方程 λ² − (2−2ωodt)λ + (1−ωodt)² = 0，判别式恰为 0：

λ = 1 − ωo dt   (双重) (2.7)

稳定条件 |λ| < 1 ⟹ 0 < ωodt < 2。取 dt = 1 ms：ωo < 2000 rad/s。

非常宽松。代入 ωo = 120：λ = 0.88 —— 稳，且恰好临界配置。

3  控制律：抵消扰动 + 指定闭环形状

3.1 第一步：把 d 减掉

由 (1.5)，若 z2 → d，则只要

u0 ≡ b0u + z2   ⟹   u = u0 − z2b0 (3.1)

实际系统就变成 dωs/dt = u0（纯积分器）。

3.2 第二步：让 u₀ 形成标准二阶闭环

被控量是位置 θs。令误差 e = θs* − θs。希望误差按标准二阶衰减：

d²e/dt² + 2ζωc de/dt + ωc²e = 0 (3.2)

代入 de/dt = −ωs，d²e/dt² = −dωs/dt = −u0：

−u0 − 2ζωc ωs + ωc²e = 0
u0 = ωc²e − 2ζωc ωs (3.3)

3.3 得到增益

把 (3.3) 代回 (3.1)：

u = ωc²b0 e  −  2ζωcb0 ωs  −  z2b0 (3.4)
kp = ωc²b0  ,   kd = 2ζωcb0 (3.5)

这就是代码里那两行的来历：

c->kp = c->wc * c->wc / c->b0;              /* ωc² / b0   */
c->kd = 2.0f * c->zeta * c->wc / c->b0;     /* 2ζωc / b0  */

量纲校验： [rad/s²] ÷ [(rad/s²)/count] = count/rad ✓ —— 所以 kp 的单位是 counts/rad，"每偏 1 弧度出多少 counts 电流"。

当前默认值（ωc=14, ζ=0.6, b0=0.00244）：

kp = 1960.00244 = 8.03×10⁴   kd = 16.80.00244 = 6.89×10³

通读一遍 (3.4)：

项名字作用
ωc²b0e位置弹簧差多少推多少
−2ζωcb0ωs阻尼器转得越快越刹车
−z2b0扰动抵消把摩擦和大 yaw 拖拽顶掉

4  为什么还需要积分项

(3.4) 的抵消依赖 z2 → d 精确。但库里摩擦是个不连续函数（sgn），ESO 只能估个大概。代码里还留了 eso_gain < 1（只抵消一部分），所以一定有残余。

纯 PD 时，若残余扰动为 dr，稳态下 dωs/dt = 0，由 (3.3) 得 ωc²e = dr：

ess = drωc²

ωc² = 196 已经很大，所以即使 dr = 1 rad/s²，ess = 0.005 rad = 0.3°。

积分项只需要很小，它的唯一职责是啃掉那点残余静摩擦。这就是 ILIM 只给 1000 counts（≈0.18 A）的原因。
c->integ += c->ki * e * dt;    /* 积分累加，单位 counts */
/* 限幅 ±ilim */
u = ... + c->integ - ...

5  速度前馈 ωref：为什么必须有

5.1 先看没有前馈会怎样

设摇杆要求一个恒定相对转速 ωr（匀速转）。稳态时 dωs/dt = 0。由 (3.4)：

0 = ωc²e − 2ζωc ωr   ⟹   ess = 2ζωc ωr (5.1)

而消耗的电流是：

u = kp ess = ωc²b0 · 2ζωc ωr = 2ζωcb0 ωr = kd ωr (5.2)
即：维持一个转速 ωr 必须付出 kdωr 的电流。于是能维持的最大转速是
ωrmax = CLIMkd (5.3)
代入旧值（kd = 1.48×10⁴，CLIM = 14000）：只有 0.95 rad/s，而摇杆满杆要 3.63 rad/s —— 差 3.8 倍，推到底也不动，手感就是"没力"。

5.2 加上前馈

把 (3.3) 改成

u0 = ωc²e + 2ζωc(ωref − ωs) (5.4)

即代码：

u = c->kp * e + c->kd * (c->wref_f - yr) + c->integ
    - c->z2 / c->b0 * c->eso_gain;

稳态时 ωs → ωref，那么 (ωref − ωs) → 0，kd 那一项自己归零：

uss = kp ess   ⟹   ess = 摩擦力对应的电流kp = 6008.0×10⁴ ≈ 0.0075 rad = 0.43° (5.5)
转速上限消失，只受电机力矩限制。

5.3 为什么前馈是 ω_ref 而不是别的

从物理上讲：u = kpe − kdωs 里，kdωs 是"阻力矩"。要匀速转就必须有驱动力矩顶掉它。但匀速转本来不需要力矩（惯性不需要 dω/dt）。

kdωs 这项本来只是人造的阻尼，不是真实物理。只要把参考转速也乘上同一个 kd 加回去，人造阻尼就"跟着参考走"，不再吃电流。
数学本质：用同一增益抵消人造阻尼的偏置。

5.4 代码里怎么算 ω_ref

摇杆积分式：每 1 ms 目标角增加 ch·SEN。所以

ωref[k] = θ*[k] − θ*[k−1]dt 
float wref_raw = (ref - c->ref_prev) / dt;
c->ref_prev = ref;
/* 限幅 ±WREF_LIM，一阶低通 WREF_LP */

为什么必须限幅 + 低通：目标是一节一节的阶梯（每 ms 跳一次），直接拿来乘 kd ≈ 6900 会把台阶放大成电流脉冲。

6  b₀：唯一需要标定的量

6.1 理论值

由 (1.4)：b0 = (kt / Jp) · (3 / 16384)。

  • GM6020 的 kt 约 0.74 N·m/A（按额定 1.2 N·m / 1.62 A 估）
  • Jp 未知（顶板 + C 板 + roll 电机的等效惯量）

6.2 估错了会怎样（好消息）

真实增益是 b0real，但增益按 b0asm 算。代入闭环：

dωs/dt = b0real u = b0real · ωc²b0asm e

对比标准二阶：

ωn = ωc b0realb0asm  ,   ζreal = ζ b0realb0asm
两个同比例缩放 ⟹ 阻尼比不变 ⟹ 闭环形状不变，只是快慢差一档。
  • b0 估小了 → 实际更慢更软（安全）
  • b0 估大了 → 实际更快更硬（可能振）

6.3 怎么实测（加负载后必须重做）

代码里已经内置方波注入：g6020.ctrl.test_sq_amp。速度响应是三角波，斜率 = b0 × 方波幅值。

  1. 拨到 MANUAL（中间），大 yaw 摇杆回中、保持静止。DISARM 会把电流置 0，方波不生效。
  2. Watch 里让控制器让开：wc = 0、eso_bw = 0、eso_comp = 0、ki = 0、ref_slew = 0。
  3. 写 test_sq_amp = 3000、test_sq_period = 200、test_sq_t = 0。三角波有平顶就降到 1500；完全不动就加到 6000。
  4. 读 g6020.ctrl.rate_last，取正、负半周各一段干净斜坡：b0 = Δωs / (Δt × 幅值)。两段平均，抵消摩擦不对称。
  5. 测完恢复 test_sq_amp = 0、test_sq_t = 0，并把 b0 写回 GIMBAL_6020_B0。
标定期间 test_sq_amp ≠ 0 会自动关闭耦合前馈，避免污染测量。加负载后预期 b0 ≈ 0.013（0.012–0.015）。

7  符号约定（最危险的地方）

7.1 三个符号

当前固件 GIMBAL_6020_OUT_TURN 填的是 +1.0，与下表早期实测的 −1 不同。以当前代码和实物方向为准；耦合前馈的方向用 GIMBAL_6020_FF_SIGN 单独校正。
名字含义实测值
eencθs 增大方向 与 wz 正方向 的关系+1（angle 增大时 INS_data.wz > 0）
物理增益物理电流 t 与 dωs/dt 的关系负（发 +8000 → angle 变小）
OUT_TURN逻辑 u → 物理电流 t 的乘数−1

7.2 为什么 kp 可以取正

定义逻辑输出 u，物理电流 t = u · OUT_TURN。

物理上 dωs/dt = −b0phys · t（负增益，实测）。代入：

dωs/dt = −b0phys · (u · (−1)) = +b0phys u

两次取反 ⟹ 在逻辑坐标系里 dωs/dt = +b0u，这就和 (1.5) 一致，所有公式才是干净的。

契约：OUT_TURN 必须取成"逻辑 u > 0 ⟹ ωs 增大"。填反 = kp 变正反馈 + ESO 反向补偿，两处一起炸。

7.3 为什么 ESO 里存的是 u_last（未乘 OUT_TURN）

因为 ESO 的模型 (2.6) 里是 b0u，这个 u 是逻辑系的。所以：

c->u_last = u;              /* 逻辑值，给 ESO 用 */
return u * out_turn;        /* 物理值，发给电机 */

7.4 取反符号怎么标定

  1. Watch 里 g6020.ctrl.clim = 0（电机不出力）
  2. 手转大 yaw，比较 dm_4310.vel 和 INS_data.wz 的符号 → 决定 GIMBAL_6020_BIG_TURN
  3. 恒发一个小电流（绕开控制器），看 g6020.angle 往哪边变 → 决定 OUT_TURN

L(s) = gb0 · ωo²(s + ωo)² · b0s = g ωo²s(s + ωo)²
  • 极点：0, −ωo, −ωo → 相位从 −90° 走到 −270°

10  一句话总结

建模：把负载方程换到相对坐标系，得到 dωs/dt = b0u + d，其中 d 里天然包含了大 yaw 的拖拽 −dωb/dt。
估计：用 ESO 把 d 实时估出来（z2），一个带宽参数 ωo 搞定。
抵消：u = (u0 − z2)/b0，抵消后系统变成 dωs/dt = u0。
控制：指定 ωc, ζ，反推 kp = ωc²/b0、kd = 2ζωc/b0。
前馈：再加 kdωref，废掉 kd 带来的"转速收费"。
解耦：因为 d 里含着 −dωb/dt，抵消它就等于解耦 —— 不需要额外做任何事。
